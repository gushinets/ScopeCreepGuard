# Идея 6: Scope Creep Guard

## Мета
- Дата: 2026-05-25
- Автор: AnyToolAi research
- Группа-источник: research_21_ideas_final
- Статус: новая
- Фаза: F4 — Коммуникация во время проекта

## Описание
Фрилансеры теряют $1K–$5K/мес на unbilled scope creep. 78% не берут деньги за out-of-scope работу. Non-native особенно уязвимы: боятся звучать грубо по-английски при отказе. Scope Creep Guard принимает исходный scope + новый клиентский запрос → сравнивает → выдаёт вердикт (in-scope / borderline / out-of-scope) + safe professional reply + опциональный шаблон Change Order.

## Бриф идеи
- **Проблема:** 57% фрилансеров и агентств теряют $1k–$5k/мес на unbilled scope creep — нет AI-инструмента, который в реальном времени сравнивает новый запрос клиента с исходным scope и генерирует профессиональный safe reply
- **Гипотеза:** Non-native фрилансеры испытывают острую боль от потери денег на scope creep (боятся отказать по-английски) и готовы платить $15–30/мес за мгновенное сравнение scope + safe professional reply
- **ЦА:** Пользователь: фрилансер / маленькое агентство / Покупатель: тот же
- **Целевой формат:** [x] Chrome Extension (сообщения в Upwork/Gmail) + Web SaaS (хранение scope)
- **MVP-функция:** Загрузил scope проекта → выделил новый запрос клиента → получил: вердикт (in/borderline/out) + professional safe reply + опциональный Change Order
- **Ограничения:** Требует хранения scope проекта (persistence); граница in/out субъективна — нужна калибровка под индустрию
- **Артефакт:** [x] Документ (Change Order — отправляется клиенту при out-of-scope)

## Контекстный слой
- **Формат продукта:** Chrome Extension + Web SaaS (scope storage)
- **Необходимый минимум:**
  - #1 Роль: онбординг-анкета (тип фрилансера, индустрия, типичный проект)
  - #2 Цель: явная — проверить новый запрос относительно scope
  - #3 Рабочий материал: исходный scope (stored) → SYSTEM; новый запрос клиента (выделение) → TASK
  - #4 Обратная связь: пользователь редактирует safe reply → паттерн "его голоса при отказе"
  - #5 Сохранение данных: да — scope проекта, история запросов, Change Orders
- **Дополнительные методы:** загрузка договора/SOW как baseline scope, история change orders в MEMORY, онбординг-анкета (индустрия: design/dev/marketing — для нюансов scope)
- **Архитектура prompt:**
  - SYSTEM: исходный scope проекта + тип фрилансера + паттерн "голоса при отказе"
  - CONTEXT: контекст платформы + история взаимодействия с этим клиентом
  - TASK: новый запрос клиента (выделенный текст)
  - MEMORY: предыдущие change orders с этим клиентом
- **Доступность в Extension:** Полная для анализа (selection capture); scope хранится в cloud (Web SaaS backend)
- **Рекомендуемая форма входа:** Chrome Extension (анализ) + Web SaaS (scope management)

## Ценность продукта
- **Для пользователя:** Защищает $1k–$5k/мес от unbilled работы; даёт профессиональный ответ без страха звучать грубо; Change Order генерируется мгновенно; снижает когнитивную нагрузку "а вдруг я не прав"
- **Value proposition:** "Знай мгновенно — это в scope или нет, и получи ответ который не обидит клиента"
- **10× эффект:** Было: 30–60 мин ручного анализа + страх + потерянные $7,800/год → Стало: <2 мин вердикт + профессиональный reply (≈15–30×)
